# QuadSwarm · обучение и устойчивость к отказу обзора

Эксперименты с бейзлайном QuadSwarm на 100 агентах. Обучение остановлено на 100 005 120 шагах агентов, затем возобновлено с этого чекпоинта и завершено на 1 000 005 120 суммарных шагах. Параметры основного прогона — RTX 3070, 16 воркеров, 2 среды на воркер, размер батча 1 280, seed 0, сценарий `o_random`.

В основе — [QuadSwarm](https://github.com/Zhehui-Huang/quad-swarm-rl/tree/e18d6925f73e3d3b35a8acb056817203ff7b8b07) и работа [Huang et al., ICRA 2024](https://arxiv.org/abs/2309.13285). Версии зависимостей и исходный коммит указаны в [environment.txt](environment.txt).

## Веса и прогоны

- [runs/](runs/) содержит полные сохранённые чекпоинты Sample Factory, включая состояние для возобновления, конфигурации и логи двух основных прогонов и двух пилотов с 16 и 32 воркерами.
- [evaluation/manifest.txt](evaluation/manifest.txt) перечисляет 17 проверяемых файлов. В него входят все 16 чекпоинтов продолженного прогона и финал прогона на 100 млн.
- [runs/SHA256SUMS](runs/SHA256SUMS) содержит контрольные суммы весов. После клонирования скачайте их через `git lfs pull`. Для проверки выполните `cd runs && shasum -a 256 -c SHA256SUMS` на macOS или `cd runs && sha256sum -c SHA256SUMS` на Linux.

## Оценка

Серия оценки запущена. Полная таблица появится после завершения 5 100 эпизодов.

Модели оцениваются с 24 агентами при стандартной плотности препятствий 0,20. Для каждого чекпоинта используются одинаковые 100 начальных сцен и три режима: исправный обзор, отказ на 0,5 с и отказ на 2 с. При отказе у 6 из 24 агентов на заданный интервал удерживаются последние доступные девять значений канала `octomap`. Они представляют расстояния до препятствий на сетке 3×3 в симуляторе. Момент отказа и выбор шести агентов одинаковы для парных прогонов одной сцены. Актор использует детерминированные действия.

`agent_success` повторяет критерий QuadSwarm — агент достиг цели и не столкнулся с препятствием или другим агентом. `swarm_success` равен единице, если этот критерий выполнили все агенты. Контакты с границами комнаты учитываются отдельным счётчиком. `selected_agent_success` считается для одной и той же шестёрки агентов во всех трёх режимах, включая исправный обзор. Разница с исправным режимом выражается в процентных пунктах.

## Повторный запуск

Подготовьте окружение исходного QuadSwarm на коммите из [environment.txt](environment.txt). Из корня этого репозитория выполните команды ниже, подставив абсолютный путь к checkout симулятора.

```sh
simulator_dir=/absolute/path/to/quad-swarm-rl
export PYTHONPATH="$simulator_dir"
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
"$simulator_dir/.venv/bin/python" -u evaluation/evaluate.py \
    --config runs/quads100-1b-w16/config.json \
    --manifest evaluation/manifest.txt \
    --output episodes-reproduced.csv --agents 24 --episodes 100 --workers 16
python3 evaluation/summarize.py episodes-reproduced.csv evaluation/manifest.txt summary-reproduced.csv
```
